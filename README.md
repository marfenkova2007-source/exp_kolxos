## Модуль системной интеграции 

Этот модуль является центральным связующим звеном проекта. Он объединяет изолированные компоненты (аналитику, парсинг данных и бизнес-логику) в единую рабочую систему через API.

### Основной функционал
- **Синхронизация потоков** между модулями `pdf_extractor`, `analytics` и базой данных.
- **Обработка меню** через Gemini API с использованием защищенного хранения ключей.
- **Асинхронное выполнение** тяжелых задач (анализ PDF) в фоновом режиме через `BackgroundTasks`.
- **Полная настройка разрешений** для бесшовного подключения фронтенд-приложения.

## Структура проекта
### Backend (Root Directory)
Здесь сосредоточены «мозги» системы:
* **`main.py`** — Центральный узел API (FastAPI). Управляет маршрутами, загрузкой файлов и очередью задач.
* **`analytics.py`** — Ядро аналитики. Взаимодействует с **Google Gemini 1.5 Flash** для распознавания меню и генерации советов.
* **`pdf_extractor.py`** — Модуль парсинга. Использует `pdfplumber` для извлечения сырого текста из PDF-меню.
* **`business.py`** — Алгоритмический модуль. Сопоставляет позиции меню с базой фермеров и рассчитывает выгоду.
* **`farm_data.db`** — Локальная база данных SQLite с актуальным каталогом продуктов «Своё Родное».
* **`HACKATHON_FINAL_DB.csv`** — Исходный датасет для формирования базы данных.
* **`.env`** — Файл конфигурации с секретными ключами (Gemini API Key).

### Frontend (`/frontend`)
Интерфейс пользователя, построенный на стеке React + Vite:
* **`src/App.jsx`** — Главный компонент. Управляет состоянием приложения: загрузка меню, переключение сезонов, фильтрация советов.
* **`src/api.js`** — Сервисный слой. Содержит методы `fetch` для общения с FastAPI (отправка файлов, получение статусов).
* **`src/assets/`** — Локальные ресурсы: брендовые логотипы (`react.svg`, `vite.svg`) и главная иллюстрация `hero.png`.
* **`images/`** — Галерея маркетинговых материалов, включая `start_image.jpg`.
* **`public/`** — Статика: `favicon.svg` и файл `icons.svg` для системных уведомлений.
* **`tailwind.config.js`** — Конфигурация стилей в фирменной палитре (Green, Yellow, Orange).

## Установка и запуск

### 1. Подготовка Бэкенда
В корневой папке проекта:
```bash
# 1. Установка зависимостей Python
pip install google-genai python-dotenv pdfplumber fastapi uvicorn pandas

# 2. Настройка API Key (создайте файл .env)
GOOGLE_API_KEY=ваш_ключ_из_AI_Studio
```
### 2. Запуск сервера
Запустите сервер из терминала командой:
```bash: python main.py ``` 

### 3. Подготовка Фронтенда
Перейдите в директорию `frontend`:
```bash
cd frontend

# Установка зависимостей Node.js
npm install

# Запуск локального сервера разработки
npm run dev
# Переход по ссылке в браузер
```

### Документация API (Swagger)
После запуска сервера интерактивная документация доступна по адресу:
URL: http://localhost:8000/docs

Swagger позволяет тестировать эндпоинты в реальном времени:
POST /analyze_menu — загрузка PDF и запуск фонового анализа.
GET /status/{task_id} — получение итогового JSON с рекомендациями ИИ.
GET /seasonal_dashboard — получение списка актуальных продуктов из БД.

## Работа с AI-аналитикой (Standalone)
Для тестирования логики ИИ отдельно от веб-интерфейса выполните команду:

```bash
python analytics.py
```
**Результаты работы модуля:**

* **#Output_Menu** — `menu_result.json`: извлеченная структура блюд и ингредиентов.
* **#Output_Tips** — `tips_result.json`: персональные бизнес-советы по категориям `Economy` и `Inspiration`.

## Безопасность и Стабильность

* **#Secrets** — Конфиденциальный ключ API вынесен в файл `.env` и надежно скрыт от репозитория через `.gitignore`.
* **#AI_Stability** — Параметр `temperature: 0.1` минимизирует риск «галлюцинаций» нейросети, обеспечивая строгие и точные ответы.
* **#Frontend_UX** — Реализована интерактивная система лоадеров и жесткая валидация периода закупки (не более 3 месяцев) для актуальности сезонных данных.
