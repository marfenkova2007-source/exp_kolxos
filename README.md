## Структура проекта
* **`/` (root)** — Бэкенд на Python (AI-аналитика, API, обработка данных).
* **`/frontend`** — Фронтенд-приложение на React + Vite.
    * `public/` — Статические ресурсы (`favicon.svg`, `icons.svg`).
    * `images/` — Маркетинговые ассеты (`start_image.jpg`).
    * `src/` — Исходный код приложения.
        * `assets/` — Вспомогательные изображения (`hero.png`, `react.svg`).
        * `App.jsx` — Основной интерфейс и логика фильтрации.
        * `api.js` — Модуль взаимодействия с Backend API.

## Установка и запуск

### 1. Подготовка Бэкенда
В корневой папке проекта:
```bash
# 1. Установка зависимостей Python
pip install google-genai python-dotenv pdfplumber fastapi uvicorn pandas

# 2. Настройка API Key (создайте файл .env)
GOOGLE_API_KEY=ваш_ключ_из_AI_Studio
```

### 2. Подготовка Фронтенда
Перейдите в директорию `frontend`:
```bash
cd frontend

# Установка зависимостей Node.js
npm install

# Запуск локального сервера разработки
npm run dev
```

## Работа с AI-аналитикой (Standalone)
Для тестирования логики ИИ отдельно от веб-интерфейса выполните команду:

```bash
python analytics.py
```
**Результаты работы модуля:**

* **#Output_Menu** — `menu_result.json`: извлеченная структура блюд и ингредиентов.
* **#Output_Tips** — `tips_result.json`: персональные бизнес-советы по категориям `Economy` и `Inspiration`.

## Безопасность и Стабильность

* **#Secrets** — Конфиденциальный ключ API вынесен в файл `.env` и надежно скрыт от репозитория через `.gitignore`.
* **#AI_Stability** — Параметр `temperature: 0.1` минимизирует риск «галлюцинаций» нейросети, обеспечивая строгие и точные ответы.
* **#Frontend_UX** — Реализована интерактивная система лоадеров и жесткая валидация периода закупки (не более 3 месяцев) для актуальности сезонных данных.
